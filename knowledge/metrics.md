# Animal 指标定义

本文档定义了Animal项目常用指标及其定义方式。

## 公式表达约定

N日表示观察窗口。新增首日记为 Day 0，因此N日指标对应新增后的第N-1天：1日对应 Day 0，2日对应 Day 1，3日对应 Day 2，7日对应 Day 6，14日对应 Day 13，30日对应 Day 29。

## 广告前端基础指标

- 广告前端指标可以反映买量效率。

| 指标 | 业务定义 | 公式 | 取值说明 |
|---|---|---|---|
| `广告成本` | 选定范围内的投放成本。APP端包含成本与媒体表的媒体折后成本及新增设备表的固定成本；H5端仅包含成本与媒体表的媒体折后成本 | APP端：`媒体折后成本求和` + `固定成本求和`；H5端：`媒体折后成本求和` | 人民币；媒体折后成本已减去媒体激励金返点等 |
| `日均消耗` | 选定范围内每天平均广告消耗 | `广告成本求和` / `所选日期数` | - |
| `媒体曝光` | 媒体侧广告曝光总次数 | `媒体曝光求和` | - |
| `媒体点击` | 媒体侧广告点击总次数 | `媒体点击求和` | - |
| `ecpm（ad）` | 每千次广告曝光的平均成本 | `广告成本求和` / `媒体曝光求和` × 1000 | - |
| `媒体CTR` | 曝光转化为点击的比例 | `媒体点击求和` / `媒体曝光求和` | 百分比 |
| `媒体CVR` | 媒体点击转化为广告新增的比例 | `广告新增` / `媒体点击求和` | 百分比 |
| `媒体CTR × 媒体CVR` | 曝光转化为广告新增的比例 | `广告新增` / `媒体曝光求和` | 百分比 |
| `CPI（¥）` | 获取一个广告新增设备的平均成本 | `广告成本求和` / `广告新增` | - |
| `整体CPI（¥）` | 获取一个广告整体设备的平均成本 | `广告成本求和` / `广告整体` | - |

## 游戏后端基础指标

- 游戏后端指标描述用户进入游戏后的设备、活跃、付费和收入表现。下表统一列出后端基础指标及其定义、公式和适用范围。

| 指标类别 | 指标 | 业务定义 | 公式 | 常见取值说明 |
|---|---|---|---|---|
| 设备规模 | `广告新增` / `新增设备` | 当前筛选人群带来的新增设备数 | `新增设备数` | 非自然量显示为`广告新增`；自然量显示为`新增设备` |
| 设备规模 | `广告回流` | 广告带来的回流设备数 | `回流设备数` | 不适用于自然量 |
| 设备规模 | `广告整体` | 广告带来的新增设备与回流设备合计 | `新增设备数` + `回流设备数` | 不适用于自然量 |
| 设备规模 | `日均新增设备数` | 每天平均新增设备数 | `新增设备数` / `所选日期数` | - |
| 在线时长 | `人均在线时长` | 每个新增设备平均首日在线时长 | `新增设备首日在线时长求和` / `新增设备数` | 单位为分钟 |
| 留存 | `N日留存设备` | 新增设备在新增后第N-1天仍活跃的设备数 | `N日留存设备数` | N=2/3/7/14/30/60/90/180 |
| 留存 | `N日留存率` | 新增设备在新增后第N-1天仍活跃的比例 | `N日留存设备` / `新增设备数` | N=2/3/7/14/30/60/90/180，百分比 |
| 付费设备 | `N日累计付费设备` | 新增设备从Day 0到Day N-1累计付费的设备数 | `N日累计付费设备数` | N=1/3/7/14/30 |
| 付费设备 | `新增设备截至当前累积付费设备数` | 截至当前累计发生付费的新增设备数 | `截至当前累计付费设备数` | 截至当前口径 |
| 付费率 | `N日付费率` | 新增设备从Day 0到Day N-1的累计付费比例 | `N日累计付费设备数` / `新增设备数` | N=1/3/7/14/30，百分比 |
| 付费率 | `截至当前付费率` | 截至当前累计付费新增设备 / 新增设备数 | `截至当前累计付费设备数` / `新增设备数` | 截至当前口径，百分比 |
| 净内购收入 | `N日累计净内购收入` | 当前筛选人群从Day 0到Day N-1累计的净内购收入 | `N日累计净内购收入求和` | N=1/3/7/14/30/60/90/180 |
| 净内购收入 | `截至当前累计净内购收入` | 当前筛选人群截至当前累计的净内购收入 | `截至当前累计净内购收入求和` | 截至当前口径 |
| 净收入 | `N日累计净收入（人民币）` | 当前筛选人群从Day 0到Day N-1累计的净收入，包含变现收入和内购收入 | `N日累计净收入求和` | N=1/3/7/14/30 |
| 净收入 | `截至当前累计净收入（人民币）` | 当前筛选人群截至当前累计的净收入 | `截至当前累计净收入求和` | 截至当前口径 |
| 毛内购收入 | `N日累计毛内购收入` | 当前筛选人群从Day 0到Day N-1累计的毛内购收入 | `N日累计毛内购收入求和` | N=1/3/7/14/30 |
| ROI | `内购N日ROI（净）` | N日累计净内购收入相对广告成本的回收比例 | `N日累计净内购收入求和` / `广告成本求和` | N=1/3/7/14/30/60/90/180 |
| ROI | `内购截至当前ROI（净）` | 截至当前累计净内购收入 / 广告成本 | `截至当前累计净内购收入求和` / `广告成本求和` | 截至当前口径 |
| ROI | `N日ROI（净）` | N日累计净收入相对广告成本的回收比例 | `N日累计净收入求和` / `广告成本求和` | N=1/3/7/14/30 |
| ROI | `截至当前ROI（净）` | 截至当前累计净收入 / 广告成本 | `截至当前累计净收入求和` / `广告成本求和` | 截至当前口径 |
| ROI | `内购N日ROI（毛）` | N日累计毛内购收入相对广告成本的回收比例 | `N日累计毛内购收入求和` / `广告成本求和` | N=1/3/7/14/30 |
| LTV | `内购N日LTV（¥，净）` | N日累计净内购收入 / 新增设备数 | `N日累计净内购收入求和` / `新增设备数求和` | N=1/3/7/14/30 |
| LTV | `N日LTV（¥，净）` | N日累计净收入 / 新增设备数 | `N日累计净收入求和` / `新增设备数求和` | N=1/3/7/14/30 |
| LTV | `截至当前LTV（¥，净）` | 截至当前累计净收入 / 新增设备数 | `截至当前累计净收入求和` / `新增设备数求和` | 截至当前口径 |
| 翻倍系数 | `整体1日-3日内购翻倍系数` | 3日净内购收入相对1日净内购收入 | `3日累计净内购收入` / `1日累计净内购收入` | 分母窗口必须成熟 |
| 翻倍系数 | `整体3日-7日内购翻倍系数` | 7日净内购收入相对3日净内购收入 | `7日累计净内购收入` / `3日累计净内购收入` | 分母窗口必须成熟 |
| 翻倍系数 | `整体1日-7日内购翻倍系数` | 7日净内购收入相对1日净内购收入 | `7日累计净内购收入` / `1日累计净内购收入` | 分母窗口必须成熟 |
| 翻倍系数 | `整体7日-14日内购翻倍系数` | 14日净内购收入相对7日净内购收入 | `14日累计净内购收入` / `7日累计净内购收入` | 分母窗口必须成熟 |
| 翻倍系数 | `整体14日-30日内购翻倍系数` | 30日净内购收入相对14日净内购收入 | `30日累计净内购收入` / `14日累计净内购收入` | 分母窗口必须成熟 |


## 通用计算规则

- `广告成本`按产品端取数：APP端必须分别从成本与媒体表读取媒体折后成本、从新增设备表读取固定成本，按相同日期、产品、展现类型和投放维度聚合后相加；H5端不读取固定成本，只使用成本与媒体表的媒体折后成本。CPI、ROI及依赖广告成本的指标均使用该口径。

- `留存`、`N日付费设备`和`付费率`默认基于当前筛选人群的`新增设备数`。广告量展示为`广告新增`，自然量展示为`新增设备`。

- 收入类指标默认按当前筛选人群计算，可以适用于广告量、自然量、测试量、`新增设备`或`回流设备`。

- `LTV`默认指整体`LTV`：分子为当前筛选人群的整体收入，分母为`新增设备数`。明确指定`新增LTV`时，分子使用`新增收入`；明确指定`回流LTV`时，分子使用`回流收入`，分母使用`回流设备数`。`回流LTV`仅适用于广告量。

- `回流设备`及回流相关指标仅适用于广告量，自然量没有`回流设备`。自然量没有对应广告成本时，不计算`CPI`或`ROI`；只有存在可匹配的广告成本时，才计算`CPI`或`ROI`。

- `N日`指标只适用于已成熟的新增日期。以今天为查询基准，新增日期到昨天的日期差达到N-1天时，`N日`窗口成熟；未成熟时不计算该日期的`N日`指标。翻倍系数的分子和分母都必须满足较长观察窗口的成熟条件。

- 所有比率、ROI、LTV、CPI和翻倍系数都要防止除零；分母为0时返回空值。

- 确认没有发生收入或成本时，空值可以按0参与汇总；字段缺失、口径不适用或作为分母的数据无效时，必须返回空值，不能按0计算。

- “净内购收入”只指内购净收入，意为扣除平台分成后收入；“净收入”包含变现收入和内购收入；“毛内购收入”不得与净口径混用。
