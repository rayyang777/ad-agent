# Animal 项目知识库

这里存放项目通用事实、数据表说明、指标口径、维度映射和 SQL 查询规则。

## 文件说明

| 文件 | 内容 |
|---|---|
| `project.md` | 项目、端口和用户归因基础信息 |
| `tables.md` | 数据表能力、粒度、字段和适用场景 |
| `metrics.md` | 指标定义、公式、口径和来源表 |
| `sql.md` | 表选择流程、路由优先级和 SQL 约束 |
| `dimensions.md` | 用户说法、维度字段和值之间的映射 |

## 使用顺序

生成查询 SQL 前，先识别用户问题中的指标、维度、时间和分析场景，再按以下顺序读取：

1. `metrics.md`
2. `tables.md`
3. `sql.md`
4. 需要识别简称或具体值时，再读取 `dimensions.md`

知识库只描述通用规则。具体 Skill 的分析流程、异常判断和报告格式继续由对应 Skill 负责。
